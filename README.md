# Análisis de Ingresos y Empleo en Ecuador (ENEMDU)

## Pregunta de análisis
¿Cuáles son los determinantes principales del ingreso laboral en Ecuador y en qué medida influyen la educación y el área de residencia?

## Fuente de datos
Datos sintéticos basados en la Encuesta Nacional de Empleo, Desempleo y Subempleo (ENEMDU) del INEC.

## Estructura del proyecto
- `data/crudos/`: Datos originales sin modificar.
- `data/procesados/`: Datasets limpios y transformados listos para análisis.
- `notebooks/`: Cuadernos de experimentación y visualización.
- `src/`: Código fuente modularizado con funciones de limpieza y utilidades.
- `reportes/`: Gráficos exportados e informes finales.

## Cómo ejecutar
1. Instalar dependencias: `pip install -r requirements.txt`
2. Ejecutar procesamiento: importar funciones desde `src.limpieza`
